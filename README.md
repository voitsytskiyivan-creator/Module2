# Electronic Library Catalog (Електронний каталог бібліотеки)

Програмний комплекс призначений для автоматизації процесів обліку, зберігання та каталогізації різноманітних друкованих видань у бібліотеці. Проєкт розроблено в межах лабораторної роботи.

🚀 **Основний функціонал**

* **Управління виданнями:** Підтримка різних типів публікацій (Книги, Журнали) з використанням перелічуваних типів (Enum) для класифікації за жанрами (SCI_FI, FANTASY, SCIENCE, HISTORY).
* **Поліморфна ієрархія публікацій:** Базовий клас `Publication` та його нащадки `Book` і `Magazine` зі специфічними атрибутами (наприклад, кількість сторінок або номер випуску).
* **Просунута обробка даних:** Використання власних ітераторів (`PageIterator`) для посторінкового виведення списку видань (по 5 штук) та перевантаження магічного методу `__lt__` для порівняння публікацій за роком видання.
* **Персистентність даних:** Повне збереження та відновлення стану системи за допомогою бінарної серіалізації (`pickle`), читання зовнішніх налаштувань із конфігураційного файлу `config.json` та експорт каталогу у формат `.csv`.
* **Інтерактивний CLI-інтерфейс:** Зручне текстове меню на базі оператора `match/case` з високим рівнем стійкості до некоректного введення даних користувачем (Fault Tolerance за допомогою блоків `try/except`).

🛠 **Вимоги до середовища**

Для запуску проєкту та збирання пакунка необхідне наступне програмне забезпечення:

* Python версії 3.10 або новішої (через використання синтаксису `match/case`).
* Інструмент збирання `setuptools` (вбудований у сучасні версії Python) або менеджер пакунків `pip`.
